* Circuit

[[https://github.com/Kiyomi-Computation-Systems/circuit/actions/workflows/ci.yml][https://github.com/Kiyomi-Computation-Systems/circuit/actions/workflows/ci.yml/badge.svg]]

An HTTP abstraction layer in the manner of [[https://github.com/ring-clojure/ring][Ring]] for R6RS Scheme.

#+begin_quote
✨ *AI Disclosure:* LLMs are used extensively in the planning and development of this project.
#+end_quote

** Requirements

- Linux or macOS, on x86-64 or arm64
- Chez Scheme 10.4.1 or later, built with threads
- libuv 1.48 or later that ~pkg-config~ can see, and a C compiler: the
  server's libuv binding builds a small C shim

Circuit runs on [[https://github.com/Kiyomi-Computation-Systems/chez-http-server][chez-http-server]], pinned under ~vendor/~.

** Status

Early. Requests, responses, middleware and the adapter onto the server work. The waiting
middleware (a timeout, a catch for errors), upgrades and a router are still to come.

** Build and test

#+begin_src sh
git clone https://github.com/Kiyomi-Computation-Systems/circuit.git
cd circuit
make submodules   # clones the pinned server and what it needs
make test         # builds the libuv shim, then runs every tests/test-*.sps
#+end_src

On a Guix host, run builds and tests in the pinned container:
~scripts/guix-env make test~. ~make help~ lists every target.

** Quick start

A handler takes a request and gives back a response:

#+begin_src scheme
(import (rnrs) (circuit) (circuit http-server))

(run-server
 (lambda (req)
   (make-res 200 '(("content-type" . "text/plain")) "hello\n")))
#+end_src

~make run PROGRAM=examples/hello.sps~ runs it on ~127.0.0.1:8080~. [[file:examples/README.md][examples/]] has more:
reading a body, streaming, and a handler that waits.

** Configuration

Settings come from the environment. The server's are its own ~CHEZ_HTTP_~ variables
(where it listens, its limits; see its [[https://github.com/Kiyomi-Computation-Systems/chez-http-server/blob/v0.9.0/docs/configuration.md][configuration]]). Circuit adds one:

| Variable                   | Default | What it sets                                                               |
|----------------------------+---------+----------------------------------------------------------------------------|
| ~CIRCUIT_PORT_PIECE_BYTES~ |   65536 | the most a piece of a port body holds; a port this size or less goes whole |

The server caps no request body by default: an app that reads one whole should set
~CHEZ_HTTP_MAX_BODY_BYTES~.
